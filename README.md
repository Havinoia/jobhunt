# 🚀 JobHunt: Asisten Karir Cerdas Berbasis AI

JobHunt adalah ekstensi browser premium yang dirancang untuk membantu Anda mendapatkan pekerjaan impian dengan kekuatan **AI (Google Gemini)**. Bukan sekadar alat pelacak, JobHunt adalah mesin kecerdasan karir yang menganalisis CV Anda secara mendalam dan memberikan skor kecocokan langsung saat Anda menjelajahi lowongan di LinkedIn.

---

## ✨ Fitur Unggulan

*   **📊 Analisis CV Instan**: Cukup upload CV PDF Anda, dan AI kami akan mengekstrak keahlian (Hard & Soft Skills) Anda secara otomatis dengan akurasi tinggi.
*   **🎯 LinkedIn Smart Match**: Dapatkan skor persentase (%) kecocokan antara profil Anda dengan deskripsi pekerjaan yang sedang Anda buka di LinkedIn secara real-time.
*   **🔍 Analisis Skill Gap**: AI kami akan memberitahu Anda skill apa yang kurang untuk posisi tertentu dan memberikan saran langkah-langkah untuk meningkatkannya.
*   **📄 View Detail & Report**: Lihat kembali CV asli Anda atau baca laporan analisis karir lengkap melalui halaman web khusus yang profesional.
*   **🔐 Manajemen Profil**: Kelola profil Anda, ganti foto (avatar), dan ubah password dengan aman melalui tab profil yang intuitif.

## 🛠️ Cara Instalasi (Untuk Pengguna)

1.  **Download** source code atau folder ekstensi ini.
2.  Buka browser **Google Chrome** (atau Microsoft Edge/Brave).
3.  Ketik `chrome://extensions` di bar alamat dan tekan Enter.
4.  Aktifkan **"Developer Mode"** di pojok kanan atas.
5.  Klik tombol **"Load unpacked"**.
6.  Pilih folder `extension/dist` yang ada di dalam project ini.
7.  Selesai! Klik ikon puzzle di toolbar browser dan sematkan (pin) JobHunt.

---

## 🚀 Cara Penggunaan

1.  **Daftar/Login**: Buka ekstensi dan buat akun menggunakan email Anda.
2.  **Upload CV**: Di tab Home, upload file CV dalam format PDF.
3.  **Analisis**: Klik "Generate AI Analysis" untuk membiarkan AI mempelajari profil Anda.
4.  **Browsing**: Buka LinkedIn, cari lowongan kerja, dan biarkan JobHunt memberikan skor kecocokan secara otomatis di layar Anda!
5.  **View Detail**: Klik tombol "View Detail" pada kartu CV Anda untuk melihat dokumen asli atau laporan lengkap.
